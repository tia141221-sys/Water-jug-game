#  Water Jug Game
A simple and interactive **Water Jug Game** developed using **Java Swing**.
The main goal of this game is to measure the target amount of water using two jugs with different capacities.

## Project Overview
The Water Jug Game is a puzzle-based game where the player uses two water jugs to obtain a specific target amount of water.
The player can perform different operations such as:
* Fill a jug
* Empty a jug
* Transfer water from one jug to another
* Check the current water level
* Complete the target amount to win the game

##Objective
The objective of the game is to measure the required target amount of water using the available jugs in the minimum number of moves.

##How to Play
1. Select a game level or target amount.
2. Use the **Fill** button to fill a jug.
3. Use the **Empty** button to empty a jug.
4. Use the **Transfer** button to transfer water between jugs.
5. Continue performing operations until the target amount is reached.
6. When the target amount is obtained, the game displays **"You Win!"**.

##Main Operations

### Fill
Fills the selected jug to its maximum capacity.

### Empty
Removes all water from the selected jug.

### Transfer
Transfers water from one jug to another without exceeding the capacity of the receiving jug.

### Win Condition
The game checks whether the required target amount has been obtained. If the target is reached, the player wins the game.
